# Impact Slug

Site institucional da Impact Slug, desenvolvido com Next.js, TypeScript e
Tailwind CSS.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Verificações

```bash
npm run lint
npm run build
```

## Logo oficial

A imagem original da marca utilizada pelo cabeçalho está em:

```text
public/images/logo-impact-slug.png
```

O componente mantém a imagem dentro de uma área responsiva com `object-contain`,
sem filtros, recortes ou alterações visuais.

## Deploy na Vercel

Importe o repositório na Vercel. O framework e os comandos de build são
detectados automaticamente, sem configuração adicional ou serviços pagos.
